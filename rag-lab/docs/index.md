# RAG-Lab

**Learn modern RAG by building all of it.**

Retrieval-Augmented Generation stopped being one technique a while ago. It's now a family of designs, each invented to fix where the last one breaks. This site teaches that family as a course: ten architectures, built from scratch in readable Python, each explained from the problem up.

## Where to start

- **Brand new to RAG?** → the [Learning path](learning-path.md). Read the chapters in order.
- **Want to run something first?** → the [quickstart](https://github.com/<user>/rag-lab#60-second-quickstart) gets you a real answer + trace in a minute. <!-- TODO: link -->
- **Here for one architecture?** → jump in from the [learning path table](learning-path.md#the-curriculum), but skim the prerequisite primers it links to.

## How each chapter is built

Every architecture chapter follows the same arc, so it reads like one coherent course: the problem → the one-sentence idea → how it works (with a diagram) → watch it work (real output + trace) → where it strains → when to use it → pitfalls → exercises. You're never handed a definition without first feeling why it matters.

## The three views

The lessons here pair with **runnable examples** and the **source** — read them together. Code is *how*; these chapters are *why*.
